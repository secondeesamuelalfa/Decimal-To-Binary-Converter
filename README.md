# 🔢 Decimal to Binary Converter

A clean, modern, and interactive web application that converts decimal numbers to their binary equivalents. What makes this project special is its **real-time call stack animation**, designed as a visual teaching tool to help beginners understand how recursion works under the hood.

## ✨ Features

- 🔄 **Instant Conversion**: Converts any valid non-negative decimal integer to binary instantly.
- 🎬 **Recursive Call Stack Animation**: Enter `5` to trigger a beautifully choreographed, 20-second visual animation showing exactly how the recursive function pushes to and pops from the call stack.
- 🛡️ **Input Validation**: Gracefully handles empty inputs, negative numbers, and non-numeric values with clear user alerts.
- ⌨️ **Keyboard Support**: Press `Enter` to convert without clicking the button.
- ♿ **Accessibility**: Respects `prefers-reduced-motion` media queries to disable animations for users who need it.
- 📱 **Fully Responsive**: Looks great on mobile, tablet, and desktop screens.
